# Sistema de Clientes

## Descripción

Sistema web desarrollado con PHP, MySQL, HTML, CSS y JavaScript aplicando una estructura basada en el patrón MVC.

La aplicación permite registrar clientes y consultar la información almacenada en la base de datos.

## Funcionalidades

- Registro de clientes.
- Consulta de clientes registrados.
- Validaciones con JavaScript.
- Conexión con MySQL mediante PDO.
- Organización del proyecto utilizando MVC.
- Interfaz web responsive.
- Uso de Git y GitHub para control de versiones.

## Tecnologías utilizadas

HTML5 CSS3 JavaScript PHP  MySQL  PDO Git GitHub XAMPP
